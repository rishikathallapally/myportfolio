# Rishika Thallapally — Frontend Developer Portfolio

Welcome to my personal portfolio website! This project showcases my skills, projects, education, and interest in frontend development.

## About the Project

This is a responsive personal portfolio website built using HTML, CSS, and JavaScript. It introduces me as an aspiring Frontend Developer and provides an overview of my technical skills, projects, and contact information.

The website is designed with a clean layout, warm colors, and responsive styling to provide a simple and user-friendly experience across different screen sizes.

## Features

- **Home Section:** Introduction and links to projects and contact information.
- **About Me:** Background, education, and current learning focus.
- **Skills Section:** Frontend and additional technical skills.
- **Projects Section:** Showcases my Image Gallery and Calculator projects.
- **Resume Download:** Allows visitors to download my resume.
- **Contact Section:** Provides links to email, LinkedIn, and GitHub.
- **Sticky Navigation:** Keeps the navigation bar accessible while scrolling.
- **Scroll Effect:** Adds a shadow to the navigation bar when scrolling.
- **Responsive Layout:** Uses CSS Grid, Flexbox, and media queries for different screen sizes.
- **Dynamic Footer:** Automatically displays the current year using JavaScript.
- **Smooth Scrolling and Hover Effects:** Improves navigation and interaction.

## Technologies Used

- HTML5 — Page structure and semantic elements
- CSS3 — Styling, layouts, transitions, and responsive design
- JavaScript — Scroll interaction and dynamic footer year
- Google Fonts — DM Sans and Playfair Display
- Git and GitHub — Version control and project hosting

## Getting Started

To run the portfolio locally:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the required files and assets are present.
4. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No build tools or package installation are required.

## Deployment

This website can be hosted using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder.
6. Click **Save** and wait for the deployment to complete.
